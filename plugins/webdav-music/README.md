# WebDAV 音乐

连接 WebDAV 服务器，浏览、搜索并播放网盘中的音乐文件；歌词与封面来自音频内嵌标签或酷狗资料。

## 能力

- 浏览：侧边栏进入「WebDAV 音乐」页，按目录浏览音频文件，支持返回、刷新与排序。
- 平铺列表：递归扫描整库生成可搜索的歌曲列表，分页浏览（每页 100 首），结果缓存于插件存储，跨会话可用。
- 播放：单曲播放、追加下一首/队尾、目录批量播放、多选操作；音频经 WebDAV Range 请求直接流式读取。
- 搜索：平铺列表关键字过滤（标题/歌手）；目录模式过滤当前目录。
- 歌词与封面：优先读取音频内嵌标签（ID3v2/FLAC/Vorbis，含 USLT 同步歌词与封面图块），可切换酷狗资料在线匹配。
- 多库管理：支持添加多个 WebDAV 服务器，库卡片可点击收起/展开（新增的库默认展开），可切换当前库。
- 任务：整库扫描注册到宿主任务中心，可随时停止；停止后保留已扫描结果。
- 设置：页内入口与宿主插件管理卡片共用同一设置面板（服务器地址、名称、用户名、密码、根目录、平铺视图、歌词与封面资料来源）。

## 已知限制

- 首次整库扫描按目录顺序逐个 PROPFIND，目录较多时耗时较长；扫描结果缓存后无需重扫。
- 扫描中止时保留已扫到的歌曲；再次扫描（重新扫描）会从头开始。
- 酷狗歌词匹配依赖宿主的 kugou.api 能力，离线环境请使用内嵌标签模式。
- 密码以明文保存在本机插件存储中（与旧版行为一致），请勿在共享设备上保存敏感凭据。
