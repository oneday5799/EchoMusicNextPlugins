# WebDAV 音乐

连接 WebDAV 服务器，浏览、搜索并播放网盘中的音乐文件；歌词与封面来自音频内嵌标签、伴生歌词文件或酷狗资料。

## 能力

- 曲库页：与本地音乐插件一致的宿主详情页结构——大封面头部（播放全部、扫描、设置）+「歌曲 / 目录」选项卡 + 排序表头 + 滚动自动加载 + 骨架屏 + 右键菜单，进出场动画走宿主共享动效。
- 歌曲列表（平铺）：递归扫描整库生成可搜索的歌曲列表，按宿主排序契约（序号/歌曲/歌手/专辑）排序，滚动到底自动加载下一页；结果缓存于插件存储，跨会话可用；整库上限 20000 首，超出后标记「结果不完整」。已播放歌曲的封面与时长显示在列表行上（来自持久化资料，不产生额外网络请求）。
- 目录浏览：按目录层级浏览音频文件，头部「返回」按钮与面包屑导航（对齐专辑钻入模式），文件夹可播放整个目录。
- 播放：单曲播放、追加下一首/队尾、目录播放；双击播放跟随宿主「播放队列模式」设置（上下文模式替换队列并定位该曲，单曲模式只播该曲，「播放全部」始终播全列表）；音频经 WebDAV Range 请求直接流式读取。
- 搜索：歌曲选项卡关键字过滤（标题/歌手，服务端排序视图一致）；目录选项卡过滤当前目录；歌曲列表支持「定位当前播放」（跨页自动补页并居中）。
- 歌词与封面：优先读取歌曲同目录的伴生歌词（`<同名>.lrc`/`.txt`），其次音频内嵌标签（ID3v2/FLAC/Vorbis，含 USLT 同步歌词与封面图块），可切换酷狗资料在线匹配；酷狗歌词与播放时读取的歌曲资料按歌曲持久化，第二次播放不再重复网络请求。
- 缓存管理：设置页「缓存」区可一键清除平铺列表、持久化的歌曲资料与在线歌词，库配置不受影响。
- 多库管理：支持添加多个 WebDAV 服务器，库行可展开/收起，可切换当前库（多库时曲库页工具栏出现库选择器）。
- 任务：整库扫描注册到宿主任务中心，可随时停止；停止后保留已扫描结果。
- 设置：页内入口与宿主插件管理卡片共用同一设置面板（服务器地址、名称、用户名、密码、根目录、默认平铺视图、资料来源），分区布局与宿主设置页一致；保存前校验服务器地址，保存失败有明确提示。

## 行为细节

- 内嵌标签优先于文件名解析：ID3v2/FLAC 标签中的标题、歌手、专辑覆盖按文件名推断的结果，文件名解析只补缺失字段（与旧版和本地音乐插件一致）。
- 目录播放以文件夹名作为队列标题与专辑名；平铺列表中的歌曲默认以所在文件夹名作为专辑（可用在线资料覆盖）。
- 「资料来源：酷狗优先」时，酷狗匹配到的封面/专辑/歌手/时长覆盖内嵌标签；「内嵌优先」时在线资料只补缺失字段，且内嵌标签已完整（含封面）时不再发起酷狗搜索。
- 队列载荷中的封面与文本字段受宿主校验器上限约束（封面 16384 字符、标题/歌手/专辑各 1024 字符），超长内容自动扣留或截断（不影响播放启动）。
- 播放队列恢复（重启应用后）时，宿主可能给歌曲 id/sourceId 加插件命名空间前缀，解析器与页面高亮/定位均已兼容该形态。
- 扫描进度发布按 300ms 合并（任务中心 1000ms），大库扫描不会饱和主线程；单个子目录读取失败（如 403）只跳过该目录并计数提示，不再毁掉整库扫描；目录列表成环时自动终止。

## 已知限制

- 首次整库扫描按目录顺序逐个 PROPFIND，目录较多时耗时较长；扫描结果缓存后无需重扫。
- 扫描中止时保留已扫到的歌曲；再次扫描（重新扫描）会从头开始。
- 不支持 Range 请求的服务器会在会话内被记忆：歌曲内嵌标签与伴生歌词读取自动跳过，资料改由文件名解析 + 酷狗在线匹配补全（避免每个文件白下载整首歌）。
- 酷狗歌词匹配依赖宿主的 kugou.api 能力，离线环境请使用内嵌标签模式。
- 密码以明文保存在本机插件存储中（与旧版行为一致），请勿在共享设备上保存敏感凭据。

## 更新日志

### v1.3.0

曲库界面与设置界面与本地音乐插件（宿主共享组件体系）全面对齐：

**界面**

- 曲库页重构为宿主详情页结构：`SongDetailHeader` 大封面头部（播放全部/扫描/设置、滚动收合）+ `EchoDetailTabs`「歌曲 / 目录」选项卡 + `SongListHeader` 排序表头 + `SongRow` 歌曲行 + 骨架屏加载 + 滚动到底自动翻页 + 页面转场动画，与本地音乐页面同一套宿主组件。
- 歌曲列表按宿主排序契约排序（序号/歌曲/歌手/专辑，服务端视图与分页、定位、播放共用同一排序），不再使用页内按钮分页。
- 已播放歌曲的封面与时长批量填充到列表行（`flat.covers` 读持久化资料，零额外网络请求）。
- 「目录」选项卡承接原目录浏览：文件夹/文件行沿用同款 60px 行样式，头部「返回」按钮与面包屑对齐专辑钻入模式；目录内文件保留大小列与无损标签。
- 移除页内批量选择工具条（对齐本地音乐：队列操作由每行右键菜单「下一首播放 / 添加到队列」承担）。
- 设置页重构为宿主设置页分区布局：图标 + 标题在卡片上方、行内 hairline 分隔（`SettingsSection` / `SettingRow` 与本地音乐同款）；资料来源改为即时保存的下拉（乐观更新，失败回退）；「平铺视图」改为「默认平铺视图」（决定进入页面时的选项卡）。

**配套后端**

- `flat.page` / `flat.locate` / `play`（平铺）统一支持 `sort`/`sortDir` 视图参数；新增 `flat.covers` 批量封面/时长命令；目录行与队列行携带专辑字段。
- manifest 增加 `cover.themed` 能力（头部主题化封面）。

### v1.2.0

第二轮对照旧 Electron 版插件与本仓库 local-music 插件的修复与对齐：

**修复**

- 修复播放行高亮与「定位当前播放」永远不匹配：宿主播放快照的歌曲 id 带 `plugin:<插件id>:` 前缀，页面比较前先剥离（本地音乐插件同款处理）。
- 修复快速翻页/修改搜索关键词时旧分页响应覆盖新页（分页请求加令牌）。
- 修复命令失败时加载态永久搁浅：run() 失败分支同样回调，flatLoading 等状态正常复位。
- 修复扫描遇单个坏目录（403、超时等）整体失败：子目录失败跳过并计数，任务与页面提示「N 个目录无法读取」；全部目录不可读时才报错；根目录失败仍然直接报错。
- 修复目录列表自引用/互引导致的扫描死循环（visited 集合阻断）。
- 修复不支持 Range 的服务器每个文件都白下载整首歌：宿主响应超限（ResponseTooLarge）后按服务器记忆，会话内跳过内嵌标签与伴生歌词读取，资料改由在线匹配补全。
- 修复标签读取瞬时失败被缓存 null 钉死整个会话：失败结果不缓存，下次播放重试（本地音乐插件同款规则）。
- 修复酷狗优先模式语义：在线匹配到的专辑/歌手/时长现在覆盖内嵌标签（原先只填空，与设置文案矛盾）。
- 修复插件停用后在飞回调"复活"已清空的缓存：enricher 会话代数守卫 + 持久化写入前检查上下文有效性。

**新增/优化**

- 平铺扫描歌曲默认携带所在文件夹名作为专辑（旧版行为），播放队列无需扫描也能带上专辑。
- 内嵌标签完整（含封面）时跳过酷狗搜索（旧版 v1.0.5 优化）。
- 队列文本字段按宿主上限截断，超长标题/歌手/专辑不再导致整条 replace 被静默拒绝。
- 页面后台时跳过扫描状态刷新，回到前台再补；扫描状态差分更新，未变化不触发重渲染。

### v1.1.0

对照旧 Electron 版插件与本仓库 local-music 插件补齐的正确性与体验：

**修复**

- 修复设置保存可能写入空库列表：`settings.patch` 仅在载荷带真正的 `libraries` 数组时才替换库列表，畸形或未加载的 draft 不再清空配置；设置页增加加载守卫、服务器地址校验与失败提示。
- 修复队列恢复后播放失败：兼容宿主队列给 sourceId 加的 `<plugin-id>/` 前缀。
- 修复超大内嵌封面导致整个 replace 被宿主静默丢弃：队列封面超过 16384 字符时扣留。
- 修复扫描进度逐目录发布导致的 UI 卡顿：进度发布按 300ms 合并（任务中心 1000ms）。
- 修复平铺缓存写入失败被误报为扫描失败；插件停用时取消在途请求。
- 修复快速连续切换目录时旧响应覆盖新目录内容（加载令牌）。
- 内嵌标签优先级对齐旧版：标签覆盖文件名解析结果。

**新增**

- 双击播放跟随宿主「播放队列模式」（context/single），「播放全部」始终播全列表。
- 伴生歌词支持（`<同名>.lrc`/`.txt`），优先于内嵌与在线匹配。
- 酷狗歌词按歌曲持久化，第二次播放直接命中。
- 播放时读取的歌曲资料（标题/歌手/专辑/封面/时长）按歌曲持久化，第二次播放零网络请求。
- 平铺列表「定位当前播放」。
- 目录播放以文件夹名作为专辑。
- 整库扫描上限 20000 首，超出标记「结果不完整」。
- 设置页「缓存」区：缓存计数展示与一键清除（含确认对话框）。
