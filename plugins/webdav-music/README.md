# WebDAV 音乐

连接 WebDAV 服务器，浏览、搜索并播放网盘中的音乐文件；歌词与封面来自音频内嵌标签、伴生歌词文件或酷狗资料。

## 能力

- 浏览：侧边栏进入「WebDAV 音乐」页，按目录浏览音频文件，支持返回、刷新与排序。
- 平铺列表：递归扫描整库生成可搜索的歌曲列表，分页浏览（每页 100 首），结果缓存于插件存储，跨会话可用；整库上限 20000 首，超出后列表标记为「结果不完整」。
- 播放：单曲播放、追加下一首/队尾、目录批量播放、多选操作；双击播放跟随宿主「播放队列模式」设置（上下文模式替换队列并定位该曲，单曲模式只播该曲，「播放全部」始终播全列表）；音频经 WebDAV Range 请求直接流式读取。
- 搜索：平铺列表关键字过滤（标题/歌手）；目录模式过滤当前目录；平铺列表支持「定位当前播放」。
- 歌词与封面：优先读取歌曲同目录的伴生歌词（`<同名>.lrc`/`.txt`），其次音频内嵌标签（ID3v2/FLAC/Vorbis，含 USLT 同步歌词与封面图块），可切换酷狗资料在线匹配；酷狗歌词与播放时读取的歌曲资料按歌曲持久化，第二次播放不再重复网络请求。
- 缓存管理：设置页「缓存」区可一键清除平铺列表、持久化的歌曲资料与在线歌词，库配置不受影响。
- 多库管理：支持添加多个 WebDAV 服务器，库卡片可点击收起/展开（新增的库默认展开），可切换当前库。
- 任务：整库扫描注册到宿主任务中心，可随时停止；停止后保留已扫描结果。
- 设置：页内入口与宿主插件管理卡片共用同一设置面板（服务器地址、名称、用户名、密码、根目录、平铺视图、歌词与封面资料来源）；保存前校验服务器地址，保存失败有明确提示。

## 行为细节

- 内嵌标签优先于文件名解析：ID3v2/FLAC 标签中的标题、歌手、专辑覆盖按文件名推断的结果，文件名解析只补缺失字段（与旧版和本地音乐插件一致）。
- 目录播放以文件夹名作为队列标题与专辑名。
- 队列载荷中的封面受宿主 16384 字符上限约束，超大的内嵌封面自动扣留（不影响播放启动）。
- 播放队列恢复（重启应用后）时，宿主可能给歌曲 sourceId 加插件命名空间前缀，解析器已兼容该形态。
- 扫描进度发布按 300ms 合并（任务中心 1000ms），大库扫描不会饱和主线程。

## 已知限制

- 首次整库扫描按目录顺序逐个 PROPFIND，目录较多时耗时较长；扫描结果缓存后无需重扫。
- 扫描中止时保留已扫到的歌曲；再次扫描（重新扫描）会从头开始。
- 酷狗歌词匹配依赖宿主的 kugou.api 能力，离线环境请使用内嵌标签模式。
- 密码以明文保存在本机插件存储中（与旧版行为一致），请勿在共享设备上保存敏感凭据。

## 更新日志

### v1.1.0

对照旧 Electron 版插件与本仓库 local-music 插件补齐的正确性与体验：

**修复**

- 修复设置保存可能写入空库列表：`settings.patch` 仅在载荷带真正的 `libraries` 数组时才替换库列表，畸形或未加载的 draft 不再清空配置；设置页增加加载守卫、服务器地址校验与失败提示。
- 修复队列恢复后播放失败：兼容宿主队列给 sourceId 加的 `<plugin-id>/` 前缀。
- 修复超大内嵌封面导致整个 replace 被宿主静默丢弃：队列封面超过 16384 字符时扣留。
- 修复扫描进度逐目录发布导致的 UI 卡顿：进度发布按 300ms 合并（任务中心 1000ms）。
- 修复平铺缓存写入失败被误报为扫描失败；插件停用时取消在途请求。
- 修复快速连续切换目录时旧响应覆盖新目录内容（加载令牌）。
- 内嵌标签优先级对齐旧版：标签覆盖文件名解析结果。

**新增**

- 双击播放跟随宿主「播放队列模式」（context/single），「播放全部」始终播全列表。
- 伴生歌词支持（`<同名>.lrc`/`.txt`），优先于内嵌与在线匹配。
- 酷狗歌词按歌曲持久化，第二次播放直接命中。
- 播放时读取的歌曲资料（标题/歌手/专辑/封面/时长）按歌曲持久化，第二次播放零网络请求。
- 平铺列表「定位当前播放」。
- 目录播放以文件夹名作为专辑。
- 整库扫描上限 20000 首，超出标记「结果不完整」。
- 设置页「缓存」区：缓存计数展示与一键清除（含确认对话框）。
