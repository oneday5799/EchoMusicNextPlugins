# 本地音乐

扫描本地文件夹中的音乐，读取标签、封面与歌词，在侧边栏「本地音乐」页浏览和播放。

## 功能

- 多文件夹管理：原生目录选择器添加（只读持久授权）、重命名、移除
- 全库扫描：递归收集音频文件（MP3/FLAC/WAV/AAC/OGG/WMA/M4A/APE/OPUS 等），任务中心显示进度、可中途停止
- 标签优先：标题、歌手、专辑、时长由宿主元数据读取；缺失时按「歌手 - 歌名」文件名解析
- 内嵌封面与歌词：解析 ID3v2.3/2.4（APIC/USLT）与 FLAC（PICTURE/VORBIS_COMMENT）；大标签自动重读完整头部
- 文件夹封面：内嵌封面缺失时回退到目录内 cover/folder/front 等图片
- 在线补全（可选，默认关闭）：缺少封面或歌词时从酷狗曲库检索
- 歌词来源：同名 .lrc/.txt 文件 → 内嵌歌词 → 在线曲库
- 浏览视图：歌曲列表（搜索、文件夹筛选、排序、无损标记、页码浏览）与专辑网格
- 播放：整库/专辑/文件夹/当前筛选视图一键播放，双击从所选曲目起播，右键「下一首播放」「添加到队列」
- 扫描结果分块缓存，重启后直接载入；文件夹变化时自动提示重新扫描

## 使用

1. 插件设置 → 「添加文件夹」选择音乐目录
2. 侧栏「本地音乐」→「重新扫描」建立曲库
3. 双击歌曲播放，或在专辑网格中点选专辑

## 设置

- **音乐文件夹** — 添加/重命名/移除扫描目录，改动即时保存
- **读取内嵌封面与歌词** — 关闭后仅使用文件夹图片与在线补全
- **在线补全封面与歌词** — 文件缺少内嵌与文件夹封面、或没有本地歌词时在线检索（默认关闭）

## 实现说明

- 播放通过宿主 `ctx.files.openMedia` 媒体租约提供本机回环地址，队列中不出现 `file://` 明文路径
- 曲目身份为 `grantId|路径` 的稳定哈希，重新扫描后队列收藏与歌词定位保持一致
- 封面按专辑代表曲目提取并缓存于插件 KV，避免整库重复读取文件头

## 已知限制

- `.lrc`/`.txt` 歌词按 UTF-8 读取，GBK/ANSI 编码的歌词文件可能乱码
- 内嵌封面与歌词解析覆盖 MP3（ID3v2.3/2.4）与 FLAC；M4A/APE 等格式的内嵌封面请依赖文件夹图片或开启在线补全
- 单个内嵌封面超过 384 KiB 时不会写入专辑封面缓存（播放时仍可显示）
