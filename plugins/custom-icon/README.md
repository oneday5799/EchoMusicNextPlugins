# 自定义图标 (custom-icon)

自定义 EchoMusicNext 的窗口图标、系统托盘图标、桌面快捷方式图标和固定任务栏图标。

移植自 EchoMusic（Electron 版）同名插件；改为基于宿主 `app.icons` 呈现 API，由宿主直接改写属于本程序已有的快捷方式，不再需要外部工具（旧版 Tool.exe）。

## 功能

- **窗口图标**：窗口标题栏与任务栏程序图标（macOS Dock）
- **托盘图标**：系统托盘区域显示的图标
- **桌面快捷方式图标**：由宿主写入桌面已有的快捷方式（Windows `.lnk`、Linux 启动器）
- **固定任务栏图标**：固定到任务栏的快捷方式（仅 Windows）

每个目标独立选择图片（≤4 MiB、≤2048×2048），立即生效；停用插件即恢复默认。宿主保留原图标字段，撤销贡献后恢复用户此前的状态。

支持 `.ico/.png/.jpg/.webp/.bmp/.gif`；宿主经 Qt 图片解码统一处理，快捷方式图标由宿主转存为对应平台格式（Windows `.ico`、Linux `.png`）后写入，无需预先转换。

## 使用说明

1. 启用插件后在 设置 → 插件 → 自定义图标 中选择各目标图片，选完即时生效。
2. 首次应用时确认「更改应用、托盘或快捷方式图标」授权；可在插件管理的授权入口撤销。若授权前已选好图片，设置页底部会出现「应用图标」按钮，点击后确认授权即可一次应用全部已选目标。
3. 「恢复默认」清除全部已选图片并恢复快捷方式默认图标。

桌面与固定任务栏图标写入后，由宿主广播 shell 刷新通知即时生效；若资源管理器仍显示缓存的旧图标，重启 Explorer 一次即可。

## 平台兼容性

| 功能             | Windows | macOS | Linux |
| ---------------- | ------- | ----- | ----- |
| 窗口图标         | ✅      | ✅    | ✅    |
| 托盘图标         | ✅      | ✅    | ✅    |
| 桌面快捷方式图标 | ✅      | ❌    | ✅    |
| 固定任务栏图标   | ✅      | ❌    | ❌    |

桌面与固定任务栏图标依赖平台，设置页会按宿主 `appIcons.snapshot` 显示可用性；这两个目标还需要宿主包含快捷方式枚举修复（Qt 的 `NoSymLinks` 过滤会排除全部 .lnk）。

## 与旧版 EchoMusic 插件的差异

| 旧版功能                     | 状态   | 说明                                                                         |
| ---------------------------- | ------ | ---------------------------------------------------------------------------- |
| 托盘/任务栏/桌面快捷方式图标 | 已移植 | 由宿主 `ctx.appIcons` 原生处理，无需 Tool.exe                                |
| 启动画面                     | 未移植 | EchoMusicNext 没有启动画面表面，宿主提供对应 API 前无法实现                  |
| 启动音效                     | 未移植 | 插件没有应用启动时的音频播放入口                                             |
| 歌单管理（隐藏/自定义封面）  | 未移植 | 无 DOM 访问；封面回退 API 仅在封面缺失或加载失败时生效，不能替换真实歌单封面 |

以上未移植项依赖宿主未提供的扩展表面，待宿主接入对应能力后再评估。
