# GitHub 加速

自动检测可用的 GitHub 加速镜像并测速选优，帮助用户改善 EchoMusicNext 中插件市场索引、安装包与应用更新的 GitHub 下载速度。移植自 xiaotian2333 的 EchoMusic「GitHub 加速」插件（MIT），云端镜像数据与其共享。

## 功能

- **镜像列表**：随包内置社区维护的 `data.json` 兜底数据，并沿用原版云端数据源（`oss.xt-url.com`）；每日首次激活自动检查更新，新版本（三段版本号比较）自动落盘到插件私有存储。
- **连通性测速**：探测列表中的全部镜像（真实资源地址 + 缓存穿透参数），非 5xx 视为可用，与原版判定一致；单镜像超时可由数据配置（1–30 秒，默认 5 秒）。
- **延迟排名**：按往返延迟升序列出最多 3 个可用地址，第 1 名标记「推荐」；同延迟时保持列表优先级顺序。
- **自动检测**：打开插件设置面板即自动触发一轮检测，无需手动点击。
- **推荐与生效**：宿主 EchoMusicNext 未把网络设置开放给插件 SDK，因此检测到最优地址后由用户一键复制，并可从设置面板直达宿主「网络设置」分区粘贴到「GitHub 加速地址」。宿主在镜像请求失败时会自动回源 GitHub。

## 与原版（EchoMusic）的差异

| 原版能力                                              | 本移植                                                                                  |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 直接写入 `ctx.settings.githubProxyUrl` 接管主程序设置 | EchoMusicNext 插件 SDK 设置服务不含 network 域，改为复制地址 + 深链直达「网络设置」分区 |
| CSS/DOM 注入隐藏宿主输入框                            | Qt Quick 宿主无 DOM；不做界面改写                                                       |
| Vue 设置面板                                          | `ctx.ui.registerSettings` 注册 QML 面板；打开即自动检测                                 |
| 首个可用镜像获胜后停止                                | 探测全部镜像，按延迟排出前 3 个可用地址                                                 |
| `fetch` + AbortController                             | `ctx.net.request`（`unrestrictedNetwork` 能力），超时由 `timeoutMs` 承担                |
| 每日首次启动检查云端更新                              | 相同；激活时检查一次，另加 24 小时重复定时器覆盖长期驻留                                |

## 使用

1. 安装并启用插件（需要确认「unrestrictedNetwork 网络」与「导航」授权）。
2. 打开插件设置面板，会自动检测并实时显示探测进度，完成后列出按延迟排序的前 3 个可用地址（第 1 名标「推荐」，每行右侧有复制按钮）。
3. 点击某行「复制」复制该地址；直接点「粘贴到设置」时，若尚未手动复制过会自动复制第 1 名，然后跳转 设置 → 网络设置，把地址粘贴进「GitHub 加速地址」。

## 数据格式

```json
{
  "version": "1.0.0",
  "update": "2026-07-27",
  "test": {
    "url": "https://raw.githubusercontent.com/EchoMusic-org/github-accelerate/main/manifest.json",
    "random": true,
    "timeout": 5000
  },
  "data": ["https://github.cnmclash.de5.net"]
}
```

`data` 为按优先级排列的镜像地址（http/https，去除尾部斜杠，最多 64 个，去重）；`test.timeout` 单位毫秒，超出 1000–30000 范围会被截断。
