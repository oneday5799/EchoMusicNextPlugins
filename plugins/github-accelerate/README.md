# GitHub 加速

自动检测可用的 GitHub 加速镜像并测速选优，帮助用户改善 EchoMusicNext 中插件市场索引、安装包与应用更新的 GitHub 下载速度。移植自 xiaotian2333 的 EchoMusic「GitHub 加速」插件（MIT），云端镜像数据与其共享。

插件提供「**自动托管**」开关（默认开启）：

- **开启（托管模式）**：激活后自动测速，把最优地址直接写入宿主「GitHub 加速地址」，并在宿主网络设置中显示接管提示、隐藏原输入框；地址变更由插件持续维护。需要宿主 `hostSettings` 能力（读取与写入各确认一次授权）。
- **关闭（手动模式）**：保持 1.0.0 的行为——打开设置面板自动检测、按延迟列出可用地址，由用户复制并粘贴到宿主「GitHub 加速地址」；插件不读取也不改写宿主设置。关闭托管会立即撤回接管提示并恢复宿主输入框，已写入的地址保留不动。

## 功能

- **镜像列表**：随包内置社区维护的 `data.json` 兜底数据，并沿用原版云端数据源（`oss.xt-url.com`）；每日首次激活自动检查更新，新版本（三段版本号比较）自动落盘到插件私有存储。
- **连通性测速**：探测列表中的全部镜像（真实资源地址 + 缓存穿透参数），非 5xx 视为可用，与原版判定一致；单镜像超时可由数据配置（1–30 秒，默认 5 秒）；8 路并发分片探测并实时显示进度。
- **延迟排名**：按往返延迟升序列出最多 3 个可用地址，第 1 名标记「推荐」；同延迟时保持列表优先级顺序。
- **自动托管（开关，默认开启）**：托管模式下启动即测速并自动应用最优地址；写入失败会在面板显示原因且不谎报成功。权限被拒或会话失效时自动撤回接管 UI，绝不隐藏宿主输入框或写入未知地址。
- **手动生效（托管关闭时）**：检测到最优地址后由用户一键复制（每行右侧复制按钮），并可从设置面板直达宿主「网络设置」分区；直接点「粘贴到设置」时若尚未手动复制过会自动补复制第 1 名。宿主在镜像请求失败时会自动回源 GitHub。

## 与原版（EchoMusic）的差异

| 原版能力                                              | 本移植                                                                                                                                                |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 直接写入 `ctx.settings.githubProxyUrl` 接管主程序设置 | EchoMusicNext SDK 1.0.0 无设置服务；1.0.1 起上游提供 `settings.observe/update` 与 `ui.parts`，托管模式下原生接管；手动模式（开关关闭）保持复制 + 深链 |
| CSS/DOM 注入隐藏宿主输入框                            | Qt Quick 宿主无 DOM；托管模式通过 `ui.parts` 在「GitHub 加速地址」前插入接管提示并临时隐藏输入框，撤回时自动恢复                                      |
| Vue 设置面板                                          | `ctx.ui.registerSettings` 注册 QML 面板，含「自动托管」开关与接管状态显示                                                                             |
| 首个可用镜像获胜后停止                                | 探测全部镜像，按延迟排出前 3 个可用地址                                                                                                               |
| `fetch` + AbortController                             | `ctx.net.request`（`unrestrictedNetwork` 能力），超时由 `timeoutMs` 承担                                                                              |
| 每日首次启动检查云端更新                              | 相同；激活时检查一次，另加 24 小时重复定时器覆盖长期驻留                                                                                              |

## 使用

1. 安装并启用插件（需要确认「unrestrictedNetwork 网络」「导航」授权；开启自动托管时还会先后确认「读取网络设置」与「写入网络设置」授权）。
2. **托管模式（默认）**：启动后自动测速并把最优地址写入 设置 → 网络设置 → GitHub 加速地址；打开插件面板可查看排名、重新检测或切换「自动托管」。
3. **手动模式（关闭自动托管）**：打开插件设置面板自动检测，列出按延迟排序的前 3 个可用地址（第 1 名标「推荐」，每行右侧有复制按钮）；点击某行「复制」后点「粘贴到设置」跳转宿主网络设置粘贴。
4. 关闭托管或停用插件后，宿主「GitHub 加速地址」输入框恢复，已保存的地址继续生效。

## 数据格式

```json
{
  "version": "1.0.0",
  "update": "2026-07-27",
  "test": {
    "url": "https://raw.githubusercontent.com/EchoMusic-org/github-accelerate/main/manifest.json",
    "random": true,
    "timeout": 5000
  },
  "data": ["https://github.cnmclash.de5.net"]
}
```

`data` 为按优先级排列的镜像地址（http/https，去除尾部斜杠，最多 64 个，去重）；`test.timeout` 单位毫秒，超出 1000–30000 范围会被截断。
